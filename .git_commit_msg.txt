fix(css): 颜色/值序列化对齐浏览器 CSSOM 格式

getComputedStyle().backgroundColor 输出 `rgb( 0 , 128 , 0 )`（每个 token
间统一加空格），浏览器为 `rgb(0, 128, 0)` —— 字符串比较/样式断言全挂。

根因：css.Declaration.String/ValueString 在 token 之间无条件加空格，
函数 token（"rgb("）后、逗号前、右括号前都多出空格；且 tokenizer 产生
的 whitespace/comment token 被原样序列化（双空格）。

修复（css/rule.go）：
- appendValueSeparator 按 CSSOM 组件值序列化规则：逗号前/右括号前无空格，
  函数名后无空格（rgb(0），逗号后一空格（0, 128），其余一空格（1px solid）
- 跳过 TokenNonNewlineWhitespace/TokenNewline/TokenComment 噪声 token
- String/ValueString 统一走 valueStringOf

验证：
- cmd/browser -verify 13/13 全过（css-style 用例改为严格断言
  bg === 'rgb(0, 128, 0)'，与 Chrome 一致）
- css 包 TestCVarTokenization 期望更新为浏览器格式
- css/style/bindings/dom/html/webkit/page/rendering/layout 全量测试通过
