feat(hostability): Go 主动调 JS + 声明式渲染 + 最小浏览器 + 内存泄漏修复

用户诉求：桌面端易用性——Go 能主动调用 JS 函数、DOM 操作类似 Vue 声明式
更新；用 wb-ui 实现一个浏览器验证全部能力；优化 wb-ui 内存占用。

## 1. Go 主动调 JS 函数（宿主调用页面）
- jsc: Interpreter.ValueOf(any) 把 Go 值转 JSValue（string/bool/int/float64/
  []any/map[string]any/nil，数组/对象在正确运行时上构造）
- webkit.WebView.CallFunction(name, args...)：点路径解析（"nav"/
  "app.nav"/"window.app.nav" 等价）、自动类型转换、this 绑定全局对象
  （验证 this===window===globalThis，与浏览器语义一致）、错误路径清晰
- 测试：TestCallFunction/TestCallFunctionThisPersist（标量/map 参数、点路径、
  全局 this 跨调用持久）

## 2. DOM 声明式更新（类 Vue 模板的宿主侧入口）
- webkit.WebView.RenderHTML(id, html)：拼 HTML 模板挂载到元素（等价
  el.innerHTML=）+ 标记渲染树脏，下一帧自动重建——Go 侧声明式刷新 UI
- bindings: innerHTML/textContent setter 触发 OnNodeInserted（此前只改 DOM
  不重建渲染树，v-html 后界面不刷新）；仅 el.IsConnected() 时触发
- 测试：TestRenderHTML

## 3. 最小浏览器（wb-ui/cmd/browser）
- 窗口模式：内置首页（地址栏 + 前进/后退/刷新 + 快捷卡片），导航走两层
  API 桥（fetch('/_browser/*') → wb-ui bridge → Go handler → LoadURL），
  历史栈 push/back/fwd/reload（浏览器语义：前进后新导航丢弃栈尾）；
  stdin 驱动 open/back/fwd/reload/home/status/quit
- 无头验证：`go run ./cmd/browser -verify` 12 用例覆盖 HTML 结构/CSS 布局
  与样式/JS DOM/事件/fetch 两层桥/定时器/表单/SVG/console/滚动几何/属性
  反射，页面 JS 自我断言 + Go 侧渲染管线校验，全部 PASS

## 4. 验证工具发现并修复的引擎缺陷
- select.value：统一走 GetAttribute 导致恒空 → 按选中 option 的 value/
  文本返回，setter 按 value 匹配设置选中
- textarea.value：反射初始文本内容
- 元素 title 反射属性（此前恒 undefined；removeAttribute 后返回 ""）
- getComputedStyle.backgroundColor：background 简写展开补值
- SVG 自闭合标签（<rect/>）：SVG 折叠为普通 HTML 后自闭合斜杠被忽略 →
  rect 成开元素把 circle/text 嵌套；treebuilder inSVGContent 判断 + 自闭合
  插入（仅 SVG 内容生效，HTML 语义不变）

## 5. 内存泄漏修复（关键：每次 LoadHTML +28MB / +38 万对象 → +0.1MB）
- 根因：bindings nodeWrapperCache（node→JSObject）从未清理、旧文档所有
  节点被 Go map 强引用永不被 GC；registeredListeners/windowEventListeners
  持有旧页面 JS 回调；dom.observerRegistry 持有旧节点观察者
- 修复：RegisterDOMBindings 检测 document 切换时统一清理（clearNodeCache
  + registeredListeners/windowEventListeners 重建 + dom.ResetObserverRegistry）
- 验证：dev/mem_probe 60 次 LoadHTML：修复前 1836MB(+1692MB) →
  修复后 60.2MB(+0.1MB)；Render 200 次 +1.2MB（可接受）；bindings/dom/
  webkit 测试无回归、browser -verify 12/12
