fix: real-page rendering — grid-template-areas + fr/flex stretch + dispatch

User reported "rendering is very broken on real pages" despite GEO 13/13
(geometry suite uses simple hand-tuned CSS; the real Vue IDE page exposed a
chain of latent layout defects). Probe pipeline: dev/static_probe renders
grid_app.html; gou-ide/dev/desktop_probe loads the actual desktop Vue SPA
through WebView and dumps geometry/pixels.

Four linked bugs fixed:

1. RenderBlockFlow.Layout dispatched only flex|inline|block by hand — grid
   (and table) containers fell through to the block path, so every grid
   child stacked vertically at full width. The IDE app-root rendered 3028px
   tall (sum of children) instead of 800px; nothing but background painted.
   Now dispatches through contextForBox (shared with RenderBox::layout).

2. style/resolver.go case "grid-area" wrote the child's area name into the
   CONTAINER's GridTemplateAreas (copy-paste bug), and GridFormattingContext
   never consumed grid-template-areas at all. Fixed: grid-area stores into
   Properties; GridFormattingContext parses the container's areas matrix
   (parseGridTemplateAreas / gridAreaRect) and places named items into their
   rectangular cell spans (gridItem.GridArea).

3. fr track sizing: content-based track sizing fed intrinsic text width into
   1fr tracks (base size 0 per CSS Grid §12.4) — a 1fr main column ballooned
   to its text width while an auto right panel already consumed the space,
   overflowing the container (titlebar/status-bar 1552px on a 1280 viewport).
   fr tracks are now excluded from both grow branches; the grid stays within
   its container (48+279+98+851+4 = 1280 exactly).

4. flex grid-item height: a flex container used as a grid item inflated to
   its content height (right-panel 1068px) instead of staying pinned to the
   grid row (748px). FlexFormattingContext now keeps a parent-set height
   (grid stretch / explicit) and clips overflow instead of growing.

Verification:
- grid_app.html renders pixel-correct: titlebar full-width, actbar 48px,
  sidebar 280px, main 752px, right 200px, status full-width (image analysis).
- desktop Vue SPA: titlebar/status-bar 1280px (was 1552), right-panel
  748px tall at the right edge, chat/conv panels inside the viewport.
- New regression tests: TestGridTemplateAreasPlacement (6-cell layout exact
  match), TestGridFrShrink (1fr stays ≈532, no balloon), TestFlexGridItemStretchPinned
  (stretch pins height), TestGridAutoFlowBasic.
- Full go test green; GEO 13/13 (19s); cmd/desktop builds.
