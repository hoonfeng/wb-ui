fix: token ring rendering + flex overflow + grid auto-track sizing

Fixes the token panel ring (settings gear) and viewport overflow:

1. SVG circle stroke-dasharray: svgCircle.paint now honors dashArray like
   ellipse (progress ring). dashLine rewritten to walk the dash pattern by
   phase — short arc segments whose start phase lay beyond the segment
   length were skipped even inside an on-interval (ring showed only ~20°
   of a 42-unit dash). Now the cache-ring green arc matches Edge exactly.

2. SVG rotate(deg cx cy): transform.go rotate now parses the center args
   and rotates about (cx,cy) — previously parseAngle("-90 24 24") failed
   and the ring started at 3 o'clock instead of 12.

3. Flex overflow: a flex item's resolved main size is restored after the
   child's own layout, so a tall child cannot balloon the item past the
   flex container (project-section 652.7→604.7). Also childNeedsHeight-
   Constraint boxes now subtract their padding/border from the remaining
   height (proj-empty 648.7→600.7, sidebar bottom 829→779).

4. Grid auto tracks: auto columns use min-content as base (was max-content,
   letting the auto right-panel take 855px and crushing the 1fr main to
   98px), fr maximizes first, then auto grows toward max-content capped
   per-track. TestGrid_VueApp passes again.

5. updateContentSize ignores zero-size boxes (title-right 8x0 ghost was
   forcing maxX=1286 → horizontal scrollbar).

Viewport content size: 1286x829 → 1284x800. GEO 13/13, all package tests
green (TestPxTransformCompose pre-existing Edge AA diff, unchanged).
