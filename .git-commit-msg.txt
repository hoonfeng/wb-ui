   - edge.go + pixels.go dropped --user-data-dir: crashed runs leave

     hang forever. Edge headless manages a temp profile per run.
   - Added 30s context timeout so a wedged browser fails fast.
   - Result: GEO 13/13 in ~22s (was hanging past 120s).

     parses via html.Parse → buildSVGDocument → paintSVGScaled into the
     background-size/position dest (svg.go + backgroundimage.go).
   - Found + fixed a real SVG bug: buildSVGDocument resolved per-element
     fill into a walk-local ctx that painting never saw — every SVG element
     rendered invisible (ctx.fill defaulted transparent). New svgFilledShape
     wrapper re-applies the resolved fill at paint time. This fixes inline
     <svg> rendering too, not just backgrounds.

     repeat-x/repeat-y single-axis, no-repeat single tile. Position defines
     the first tile's location (pattern stays aligned for negative offsets).
