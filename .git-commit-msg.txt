2. Grid auto-placement BUG: auto items used a naive cursor that ignored
   occupied cells, overlapping explicitly placed or spanning items.
   Rewrote placement with an occupancy matrix: explicit/spanning items
   are marked first, auto items scan row-major for the first free cell
   (matches Edge's sparse flow — probe: auto item falls to col1,row2
   instead of colliding with the col1-2,row1 span).

   `grid-column:3` (end line 4 on a 3-track grid) wrongly created an
   extra implicit column, shifting subsequent auto items. Expansion now
   uses end-1 (track count), so an end line of nTracks+1 (far edge of
   the explicit grid) creates no implicit track.

4. layout_grid case extended to 15 elements: explicit placement,
   column/row spans, and span+auto mix verified against Edge (0 diffs).
