feat: async image loading + SVG gradients/strokes + img SVG + overlay scrollbars

Candidates round:

1. Async http(s) background images (backgroundimage.go + async_image_test.go):
   - loadBackgroundImage now returns nil for http(s) URLs on first call and
     spawns a goroutine (fetchBackgroundImageAsync); the cache serves the
     image on later paints, so network latency never blocks the render
     thread. data: URIs and files stay synchronous.
   - SetBackgroundImageLoadedCallback(url) fires after a fetch completes so
     hosts can schedule a repaint.

2. SVG gradients, strokes + a real SVG parsing bug (svg.go + svg_gradient_test.go):
   - Found: dom.Element.LocalName() lowercases ("linearGradient" →
     "lineargradient"), but parseGradientElement and the <defs> walk compared
     camelCase → gradient/clipPath defs were never collected (gradients
     silently dropped). Fixed both to lowercase comparisons.
   - svgFilledShape now carries gradientID + stroke + strokeWidth (was fill
     only), so fill="url(#g)" gradients and stroke= actually paint.
   - svgDocument stores defs gradients/clips; paintSVG injects them into the
     fresh per-call context (previously the defs were lost between build and
     paint).
   - paintGradientOnShape: default linear gradient paints pixel columns
     (canvas only supports vertical FillLinearGradient) → horizontal red→blue
     verified.

3. <img> SVG sources (painter.go PaintImage): img without an attached
   DecodedImage now lazily loads src via the shared image cache; SVG srcs
   (data:image/svg+xml) parse and paint scaled into the content box.
   TestPaintImageSVG verifies center red / corner transparent.

4. Overlay scrollbars (renderpipeline.go + scrollbar_overlay_test.go):
   - overflow:auto scrollbars render only while the cursor is over the box
     (overlay behavior); overflow:scroll stays always visible.
   - Overflow clip now triggers on EITHER axis (overflow-y:auto alone must
     clip + paint its scrollbar); previously the AND condition meant a
     single-axis scroll box never got scrollbars.
