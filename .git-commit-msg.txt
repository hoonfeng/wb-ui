fix: background shorthand reset + flex-row intrinsic + Edge pixel probe

Continuing the desktop Vue-app probe (gou-ide/dev/desktop_probe), built a
full-pixel Edge headless comparison: serve dist over local HTTP (ES modules
are blocked on file://), screenshot via Edge headless with --virtual-time-budget,
render the same page through wb-ui's jsc path, and diff the two 1280x800
images. Initial diff was 98.8% (Edge blank due to CORS), then 4.0%, now 2.8%.

Root causes found and fixed:

1. background shorthand did not reset all sub-properties: `background: none`
   cleared background-image but LEFT background-color at the UA button face
   (#f0f0f0), so Vue buttons styled with `background: none` painted the light
   UA face instead of the transparent activity bar. CSS Backgrounds-3 resets
   every sub-property to its initial value; a value without a color resets
   background-color to transparent. (desktop buttons now match Edge; pixel
   diff 4.0% -> 2.8%.)

2. intrinsicContentHeight regression from the previous round: the block-sum
   heuristic also summed children of FLEX ROW containers (which size by
   max-child on the cross axis), inflating the chat-input-area to 396px and
   shifting rp-body down 69px. Summing is now restricted to true block
   (non-flex/grid) containers; flex/grid containers keep max-child height.
   (chat-input-area back to 196px, rp-body at y=67.)
