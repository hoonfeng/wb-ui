feat: SVG <symbol> + userSpaceOnUse + clip shadow + text rotate + blend

Candidates round:

1. SVG <symbol> via <use> (svg.go + svg_symbol_test.go):
   - <symbol> templates were collected by id but parseSVGElement returned nil
     for them, so use href="#sym" silently dropped the content. Now <use>
     referencing a <symbol> renders each child shape with fill resolution and
     the use x/y offset applied to the whole set; walk skips <symbol> subtrees
     (template-only, never painted directly).
   - Verified: red+blue rects inside a symbol render at use(10,10).

2. SVG gradientUnits=userSpaceOnUse (svg.go + svg_style_test.go):
   - New svgGradient.userSpaceOnUse flag; when set, x1/y1/x2/y2 (and radial
     cx/cy/r) are absolute user-space coordinates instead of bbox percentages:
     the bbox-center fallback and bbox-projection are skipped, projecting
     directly onto the absolute axis.
   - Verified: two rects share one absolute 0..100 axis (left red, right blue).

3. CSS clip-path composes with box-shadow (clip_path_test.go):
   - Confirmed box-shadow is drawn inside PaintBackground, so an inset clip
     trims the shadow spill — added TestClipPathInsetShadow.

4. SVG text rotate + letter-spacing (svg.go + svg_style_test.go):
   - rotate="45" draws the whole text block rotated around the anchor point
     (canvas Save/Translate/Rotate/Restore); letter-spacing draws character
     by character with added advance.
   - Verified: rotate=90 makes horizontal text vertical.

5. CSS mix-blend-mode (canvas.go + renderpipeline.go + blend_test.go):
   - New Canvas.SaveLayerWithBlendMode (offscreen layer composited with the
     skia blend mode on Restore); paintObjectBackground wraps boxes with
     mix-blend-mode in such a layer; parseBlendMode maps all CSS values
     (multiply/screen/overlay/darken/…/luminosity).
   - Verified: blue box with multiply over gray yields blended #000080, while
     non-overlapping top region stays opaque blue.

6. Scrollbar drag interaction — already implemented in a previous round
   (drag/hover/auto-hide/keyboard scroll); no change.
