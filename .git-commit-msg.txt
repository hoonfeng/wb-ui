fix: flex gap in justify space + border-box grow padding

Two flex layout bugs found with desktop_probe on the real Vue IDE:

1. The file-explorer column overflowed its sidebar by 4px, so
   sidebar-content (overflow:auto) grew a scrollbar that covered the whole
   sidebar height instead of the file tree. flex:1 items with
   box-sizing:border-box had their padding excluded from the flex base
   size, so the grown content size + padding overshot the slot by exactly
   the padding (project-section 605px in a 601px slot → sidebar content
   720 > 716). distributeFreeSpace now deducts the grow items' main-axis
   padding from the distributable free space, so border-box items exactly
   fill their slot; sidebar no longer scrolls and the spurious scrollbar
   is gone.

2. justify-content:center/flex-end on a flex column shifted items too far
   by half the inter-item gap sum: freeGap = mainSize − Σitems ignored the
   explicit gap, so welcome (3 items, 2×8px gaps) sat 8px low in the
   editor. center/flex-end now compute freeGap minus gap×(n−1), aligning
   items+gaps as one group (welcome-logo y 261.9 → 253.9, exact center).
