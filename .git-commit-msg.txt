feat: SVG stroke caps/joins, fill-rule, opacity, dashoffset, viewBox meet

Completes the remaining SVG presentation-attribute gaps:

1. stroke-linecap / stroke-linejoin (round/butt/square, miter/round/bevel):
   new graphics.Canvas.StrokePath paints a polyline through the native
   Skia stroke so caps and joins match the browser exactly. Every SvgIcon
   feather icon sets stroke-linecap="round" + stroke-linejoin="round" on
   its <svg> root — previously all strokes were butt/miter.

2. fill-rule (nonzero/evenodd): parsed, forwarded and applied via
   Path.SetFillType (note: the goskia binding currently ignores evenodd,
   falls back to winding — API is in place for when the binding is fixed).

3. Native path fill: svgPath/svgPolygon now fill through graphics.Canvas.
   FillPath (skia path) instead of the triangle fan — the fan painted the
   wrong interior for concave / self-intersecting shapes.

4. opacity / fill-opacity / stroke-opacity multiply the fill/stroke alpha.

5. stroke-dashoffset drives the dash phase.

6. viewBox scaling now uses preserveAspectRatio="xMidYMid meet" (uniform
   scale, centered) instead of independent x/y stretching.

7. clipShapesToPath extended: ellipse + polygon added (was rect/circle).

Tests: svg_enhance_test.go (line cap round vs butt pixels, fill-rule
forwarding, fill-opacity alpha, viewBox meet) + graphics evenodd note.
