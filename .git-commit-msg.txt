fix: SVG polygon points/stroke/currentColor + circle dash

Continuing the desktop Vue-app probe (icon_cmp / svg_ring / send_svg /
comp_check), five SVG drawing defects fixed:

1. SVG path H/h and V/v commands were never parsed — paths with horizontal /
   vertical lines (folder icon M22 19H4V5h5l2 3h9z) drew only stray arcs.
   Added H/h/V/v cases (relative/absolute); the activity-bar folder icon now
   draws its full outline (85 → 123 ink px, structure matches Edge).

2. svgPolygon only filled triangles and never stroked — stroke-only icons
   (send-btn paper plane: fill="none" stroke="currentColor") drew nothing.
   Now strokes the outline (closed for polygon, open for polyline) with
   dasharray support, and fills a full triangle fan for multi-point polygons.

3. parseSVGPoints split on whitespace then ParseFloat'd "0,0" whole — every
   comma-separated polygon collapsed to a single (0,0) point. Now tokenizes
   numeric literals (whitespace and/or commas).

4. fill/stroke="currentColor" resolved to the black fallback. svgDocument now
   carries currentColor set from the host element's CSS color
   (paintObjectForeground), so e.g. the white send icon renders white.

5. circle/ellipse stroke-dasharray ignored — progress rings drew a full
   circle. svgEllipse.paint samples the outline (96 segs) and draws dashes
   with cumulative arc-length offset.

Regression tests: TestSVGPathHVCmds (M/H/V/h/l/z), TestSVGPolygonStroke
(3-point triangle stroke ink), plus existing suite.

Full go test green; Edge pixel diff 2.9% -> 2.8% (send-btn region
1302 -> 1223).
