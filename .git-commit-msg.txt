Extends the pixel comparison suite from 9 to 16 cases and fixes the engine
BUGs they exposed:

1. rendering/shadow.go — multi-shadow z-order: the FIRST shadow must paint
   on TOP of later ones (CSS). Painter iterated forward so later shadows
   covered earlier ones; now reversed. px_multishadow: 2.6% → 0 px.

   gradients painted past the curve (the old comment promised clipping but
   never did it). New Canvas.ClipRoundRect (skia rounded-rect path) clips
   the gradient fill. px_roundgrad: 10.6% → 0.27% (AA band).

3. rendering/gradient.go + style/resolver.go — radial-gradient support
   (circle/ellipse, center, farthest-corner sizing), extracted by the
   background shorthand like linear-gradient. px_radial: 0 px diff.

4. rendering/renderpipeline.go — static CSS transform composition:
   walkSubtreeExcluded now applies the transform around the element's
   transform-origin (default 50% 50% = box center, matching CSS; the old
   per-box tryApplyTransform rotated around the canvas origin and never
   transformed children). paintObjectBackground no longer re-applies it.
   px_transform: 9.6% → 0.52% (rotated-edge AA band).

5. rendering/painter.go — 3px dashed borders now paint 6px dash / 6px gap
   (Edge's pattern) instead of 9/3.
